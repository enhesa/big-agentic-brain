# Configuration

Generated by `pnpm docs:config` from `lib/config-spec.mjs`. Do not edit by hand.

| Variable | Default | Description |
|---|---|---|
| `BAB_ACCENT_COLOR` | `#1a3360` | Accent colour of the web UI, lowercase #rrggbb. |
| `BAB_ALLOWED_EMAILS` | unset | Comma-separated emails allowed to use BAB. Unset: anyone matching the email pattern. |
| `BAB_API_TOKENS` | unset | Comma- or newline-separated API tokens; an entry may be token=email to bind a token to a person: that address then acts only with its token, never through headers, devices, connections, bab_identify or proxy headers on /api and /mcp. A bare token only gates access, so its holder still says who they are; BAB warns at startup. Unset or empty with no proxy identity: open mode; set but holding no token (blank lines only) refuses to start. Masked in logs. |
| `BAB_API_TOKENS_FILE` | unset | Path of a file with tokens in the same format as BAB_API_TOKENS, one per line; lines starting with # are comments. Merged with BAB_API_TOKENS when both are set. |
| `BAB_AUDIT_RETENTION_DAYS` | `365` | Days the audit log is kept (positive integer). |
| `BAB_CLIENT_IP_HEADER` | unset | x-real-ip or x-forwarded-for-rightmost: the header that carries the client address (audit log, rate limits, device list). Unset: the address is unverified. |
| `BAB_DEVICES` | `true` | Off ignores X-Bab-Device and Mcp-Session-Id: nothing is remembered, only X-Bab-Actor-* callers are served. Accepts 1/true/yes/on and 0/false/no/off. |
| `BAB_EXTRA_APPLIES_TO` | unset | Comma-separated extra platform labels for a memory's applies-to list, added to the built-in ones (lowercase letters and hyphens). A label already stored on a memory stays readable when it is not listed; only writes and filters are checked. |
| `BAB_HEADER_EMAIL` | `x-auth-request-email` | Name of the proxy header that carries the user's email. |
| `BAB_HEADER_NAME` | `x-auth-request-preferred-username` | Name of the proxy header that carries the display name. |
| `BAB_HEADER_ROLES` | `x-auth-request-groups` | Name of the proxy header that carries the roles or groups. |
| `BAB_HEADER_USER_ID` | `x-auth-request-user` | Name of the proxy header that carries the user id. |

| `BAB_LOCALE` | `en` | Locale used to format dates. |
| `BAB_MAINTAINERS` | unset | Comma-separated long-form emails of the maintainers (pin and unpin house rules, feedback status, flagged standards, /usage detail, /admin/*). In open mode a maintainer identity is only as trustworthy as the caller's self-declared headers, so pair it with bound tokens or a sign-in proxy. |
| `BAB_MAX_BODY_BYTES` | `1048576` | Largest accepted request body, in bytes (positive integer). |
| `BAB_MCP_TOOLS` | `full` | Default MCP tool list: full (all tools) or lean (bab_search, bab_learn, bab_react only, about 90% fewer input tokens per request). One connection can choose with ?tools=lean or ?tools=full on the MCP URL. |

| `BAB_PROXY_SECRET` | unset | Shared secret the proxy sends in the x-bab-proxy-secret header before its identity headers are trusted. Required when BAB_TRUST_PROXY_IDENTITY is on, unless BAB_TRUST_PROXY_WITHOUT_SECRET=1. Masked in logs. |
